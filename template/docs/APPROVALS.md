# Owner の承認の記録

承認は「対象の版・サービス・価格・操作範囲・期限・出典（Owner の発言そのまま）」で残す。同じ範囲なら再承認は要らない。取り消しや却下も消さずに追記する。

## 記入例
## YYYY-MM-DD <案件ID> 出品の承認（Owner）
- 対象：<案件ID> <販路>「<商品名>」。品質管理で合格した版に限る（重大な差し止め中は出さない）。
- 価格：<金額>・<納期>・<修正回数>
- 操作範囲：Owner が手順書 owner-guides/<番号> に従って出品する。AI はサイトの画面を操作しない。
- 期限・撤退：公開から30日で購入0件なら停止する。
- 出典：YYYY-MM-DD Owner「（発言をそのまま）」
