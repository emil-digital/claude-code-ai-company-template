# /sync — 相手社との状態同期

共有フォルダ：`../shared/`（自社欄は `../shared/self/`、相手社欄は `../shared/partner/`。導入時に実際の場所へ書き換える）

1. **読む**（書かない）
   - `partner/STATUS.md` と `partner/TO_SELF.md`（無ければ「相手社は未記入」として扱う）
2. **照らし合わせる**
   - 作業の重複や、同じ販路アカウントの操作の衝突・二重公開がないか（同じ市場を扱うのは可）
   - 両社の Owner への依頼が重複していないか（同じ操作を二重に頼まない）
   - 相手社からの依頼（レビューなど）があれば、STATUS.md の次の作業に入れる
3. **書く**（直前に読み直し、自社のファイルだけ）
   - `self/STATUS.md`：販売中・準備中の商品（URL・価格・公開日）、確定した売上（観測日つき。未観測は未観測と書く）、Owner への依頼と所要時間、次の一手
   - `self/CASES.md`：案件ID・担当会社・販路とアカウント・状態（状態が変わるたび）
   - `self/TO_PARTNER.md`：相手社への依頼・連絡（追記する。古い項目は消さず「済」を付ける）
4. 自社の STATUS.md に「最終同期：日時、気付いた重複や依頼」を1行残す。

`partner/` には書き込まない（.claude/settings.json の deny を絶対パスで設定すれば、Write・Edit ツールは止まる。ただし Bash を自動許可していると、スクリプト経由の書き込みは止まらない。README の手順5で確かめること）。
